# pysystemtrade learning guide

This site presents the original pysystemtrade documentation as a searchable,
navigable website. The Markdown files remain the source of truth; this page and
the sidebar are only a reading guide.

## Suggested reading order

1. **[Installation](installation.md)** — set up Python, `uv`, and the project.
2. **[Introduction](introduction.md)** — work through a simple trading rule and
   a simple system.
3. **[Backtesting](backtesting.md)** — learn how to configure and run systems.
4. **[Instruments](instruments.md)** and **[Data](data.md)** — understand the
   futures markets and price data a system uses.
5. **[Interactive Brokers](IB.md)** — connect the project to a broker.
6. **[Production](production.md)** — operate a live system, then use the
   monitoring and strategy-change guides as needed.

## Reading tips

- Use the search box for class names, configuration keys, and error messages.
- The table of contents on the right follows the headings on the current page.
- Use the copy button on code examples rather than manually selecting long
  command blocks.
- Switch between light and dark mode using the button in the header.
